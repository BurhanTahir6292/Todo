# Todo App

A simple and responsive Todo application built with React and Vite.

## Features

- Add new tasks
- Mark tasks as completed (toggle strike-through)
- Clean and lightweight interface

## Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)

## Getting Started

### Prerequisites

Ensure you have Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:BurhanTahir6292/Todo.git
   cd Todo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
